# Single-Page-App

11.5 Lab: Single Page App

I created a Meal Finder is a one-page web app where you can search for a dish and see its photo, region, and category. You can click "View recipe" to see the ingredients, instructions, and a link to a video tutorial. :) 

## How it works

The app uses the JavaScript "fetch()" API to get data from [TheMealDB](https://www.themealdb.com/), a free public API from the Public APIs list. When you search, the app sends a request, turns the response into JSON, and builds a card for each meal on the page.

## Files

- index.html: the page structure
- styles.css: all the styling, including a food-themed color scheme and a CSS Grid layout for the meal cards
- app.js: JavaScript
